# Examples

`synthetic_FeN6.xyz` contains 19 frames. Each frame is an FeN6 sphere with a random distortion that
has exactly one of the 19 standard point groups (named in the frame's comment line), in a random
orientation. Open it in vanVleck and click the Fe atom of each frame to see the assigned point
group, the standard frame and the pattern of zero / non-zero Q values. The same file is used by the
tests in `tests/`.

Crystal structures are not distributed with this repository. The structures shown in the
screenshots in `docs/` are from C. Carbonera et al., *Dalton Trans.*, 2006, 3058–3066
(CCDC 296687–296693) and can be obtained free of charge from the Cambridge Crystallographic Data
Centre (https://www.ccdc.cam.ac.uk/structures/).
